# 精确分集观看清单

核对日期：2026-10-22；核对的是公开分集元数据，非逐集试听结论。P 号以本文件对应 BVID 为准。[完整原始目录](course-catalog.json) 含全部 373 集。

阅读方式：按 [主指南](README.md) 的 L01–L16 顺序看，不按本页课程序号从头刷。范围行给出首尾直达链接；中间 P 可在播放器选集。一个分集出现于多个学习单元只需学习一次。

“主线”指按本项目岗位目标选出的内容，不代表每一集都适合无基础者直接跳看；遇到不懂的术语，回补相邻基础集。选看和暂缓不是课程质量评价。

## 总量与取舍

以上去重后的主线约 192 集、原速 35 小时 23 分，不是 373 集全部刷完。课程时间只占学习的一部分，读代码、测试和补缺口通常还需要更多时间。

没有对应视频的部分不要硬找 P 号：SQL/PostgreSQL 调优、Spring Security、Streams/Lua、RRF/rerank/评测、Neo4j/GraphRAG、MCP、React/Next/ECharts、测试与部署，均已在主指南对应单元给出官方补学入口。
