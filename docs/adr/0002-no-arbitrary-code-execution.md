# ADR-0002：不执行模型生成的任意代码

- 状态：Accepted
- 日期：2026-09-18
- 决策者：项目维护者

## 背景

数据分析 Agent 常用 Python 代码执行完成清洗和绘图，但这会把模型输出提升为进程权限：读取文件、访问网络、窃取凭据或绕过数据库策略都可能发生。这个项目的核心价值是可控的企业数据访问，不需要通用代码执行才能完成 Northwind 分析。

## 决策

- 模型只产生受 Pydantic 校验的计划、SQL 草案和结构化图表规范。
- SQL 必须经过 SQLGlot AST、schema/table/column allowlist、成本检查和数据库只读事务。
- 图表由前端渲染固定类型的结构化规范，不使用 `eval`、`Function`、脚本字符串或模型 HTML。
- Python Agent 不提供 shell、Notebook、动态 import 或任意 URL 获取工具。

## 后果

系统不能完成需要自定义代码的数据科学任务，但攻击面、审计复杂度和多租户隔离风险显著下降。未来若必须加入代码执行，只能作为独立沙箱服务并经过新的威胁模型与 ADR，不能直接加入现有 Agent 进程。
